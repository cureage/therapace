Detailed Description

Builds a IXNReaderMuse that plays back the packets in the given IXNMuseFileReader It exposes a way to set the configuration with chainable method calls, e.g.:

IXNReaderMuse *muse = [[[ReaderMuseBuilder get]
withPacketTypes: myPacketTypes]
build: myMuseFileReader];
