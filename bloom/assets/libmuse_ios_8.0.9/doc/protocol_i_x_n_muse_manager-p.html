Detailed Description

Discovers the available Muse headbands that this device can connect to.

To connect to a headband, first call IXNMuseManager::setMuseListener to receive callbacks when a headband is discovered. Then call startListening (IXNMuseManager-p): When IXNMuseManager detects a headband you will receive a museListChanged (IXNMuseListener-p): callback. You can then call getMuses (IXNMuseManager-p): followed by the appropriate function on the IXNMuse to connect to the headband.

◆ removeFromListAfter:

- (void) removeFromListAfter: (int64_t) time

IXNMuseManager will automatically remove a Muse 2016 ( MU_02 ) or later headband from the list of Muses if it has not received some type of communication from the headband within this time period.

By default this is 30 seconds To have Muse 2016 ( MU_02 ) or later headbands remain in the list until the next call to startListening: set the time to 0.

Parameters
timeSpecified in seconds, the time to wait before removing a headband from the list. If set to 0, headbands will not be removed automatically.

◆ startListening

- (void) startListening

Start listening for any possible Muse devices.

As Muses are discovered, they are added to the list returned by getMuses:

Listening is a fairly heavyweight operation, so it should be disabled when it is not needed, e.g. after a device has been found. Specifically, you must call MuseManager::stopListening: before you try to connect to a Muse you have previously discovered.

MU-01 devices are discovered as they connect to the device, either by re-establishing a connection to the last iOS device they connected to, or by the user connecting to them from the OS's Bluetooth settings. If they go offline, they are removed from the list.

Any already-known Muse 2014 ( MU_01 ) devices will be added to the list immediately; others will trickle in as events are received.

Muse 2016 ( MU_02 ) and later devices are discovered as their discovery events are passed to the library from the OS.

◆ stopListening
